# Flexecution

This is your one stop shop to track all your exercises

## Getting Started

These instructions will get you a copy of the project up and running on your local machine for development and testing purposes.

### Prerequisites

[Here is the repo for the connected backend](https://github.com/StuvaScript/06-jobs-api)

1. Download the backend repo and run the following commands to get it running locally:

```
npm i
npm start
```

2. You will need to create a `.env` file and copy the contents of the `.env.example` file into the `.env` file and fill in the values with your own credentials.

### Installing

Run the following commands to get this frontend repo running locally:

```
npm i
npm run dev
```
